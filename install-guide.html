1المتطلباتRequirements

  • جهاز يعمل بنظام Windows 10 أو Windows 11 بنسخة 64-بت.
  • صلاحية مسؤول (Administrator) على الجهاز مرة واحدة أثناء التثبيت.
  • مساحة فارغة 300 ميجابايت تقريباً.
  • اتصال بالإنترنت: كل البيانات (الحجوزات، الخدمات، العملاء...) على الخادم.
  • رقم جوال وكلمة مرور لحساب موظف في وريد حجوزات، نفس حساب تطبيق الجوال.
  • لا حاجة لتثبيت .NET أو أي برنامج آخر: كل ما يلزم موجود داخل المثبّت.
  • A PC running Windows 10 or Windows 11, 64-bit.
  • Administrator rights on the PC, once, during installation.
  • About 300 MB of free disk space.
  • An internet connection: all data (bookings, services, customers…) is on the server.
  • A Wrid staff account (mobile number and password), the same one as the mobile app.
  • No need to install .NET or anything else: the installer contains everything.

3التثبيتInstall

  1. انقر نقراً مزدوجاً على WridMyReservation-1.0.0-x64.msi.
  2. إذا ظهرت نافذة «حمى Windows جهاز الكمبيوتر» (SmartScreen): اضغط «مزيد من المعلومات» ثم «تشغيل على أي حال». تظهر لأن الملف غير موقّع رقمياً بعد.
  3. في نافذة الترحيب اضغط Next. اترك مجلد التثبيت كما هو (C:\Program Files\Wrid MyReservation) واضغط Next. في صفحة الخيارات اختر «تشغيل البرنامج بعد التثبيت» (مفعّل افتراضياً) و«إنشاء اختصار على سطح المكتب» (مفعّل افتراضياً) و«التشغيل تلقائياً مع بدء Windows» (غير مفعّل افتراضياً)، ثم Next وInstall.
  4. وافق على طلب صلاحية المسؤول (UAC) بالضغط على نعم.
  5. اضغط Finish. ستجد اختصار «Wrid وريد حجوزات» في قائمة ابدأ، وعلى سطح المكتب إذا اخترته.
  1. Double-click WridMyReservation-1.0.0-x64.msi.
  2. If "Windows protected your PC" (SmartScreen) appears: click More info, then Run anyway. It shows because the file is not code-signed yet.
  3. On the welcome page click Next. Keep the install folder (C:\Program Files\Wrid MyReservation) and click Next. On the options page choose "Launch after installation" (on by default), "Create desktop shortcut" (on by default) and "Start with Windows" (off by default), then Next and Install.
  4. Accept the administrator prompt (UAC) with Yes.
  5. Click Finish. A "Wrid وريد حجوزات" shortcut is in the Start menu, and on the desktop if you chose it.

تثبيت صامت (لعدة أجهزة)

Silent install (many PCs)

من نافذة «موجّه الأوامر» بصلاحية المسؤول، في مجلد الملف:

From an administrator Command Prompt, in the file's folder:

msiexec /i WridMyReservation-1.0.0-x64.msi /qn

الخيارات في التثبيت الصامت: DESKTOP_SHORTCUT=0 بدون اختصار على سطح المكتب، وSTART_WITH_WINDOWS=1 للتشغيل مع بدء Windows. يُحفظ الاختيار للتحديثات القادمة.

Options for a silent install: DESKTOP_SHORTCUT=0 for no desktop shortcut, START_WITH_WINDOWS=1 to start with Windows. The choice is kept for later updates.

4أول تشغيلFirst run

  1. افتح «Wrid وريد حجوزات». اللغة الافتراضية العربية، ويمكن تغييرها من الإعدادات.
  2. أدخل رقم الجوال (مثال 05XXXXXXXX) وكلمة المرور، ثم اضغط تسجيل الدخول.
  3. تظهر لوحة التحكم. القائمة الجانبية فيها الحجوزات والخدمات والعملاء وبقية الأقسام حسب صلاحيات حسابك، وقسم الدايت للشركات التي تعمل بالدايت فقط.
  1. Open "Wrid وريد حجوزات". It starts in Arabic; Settings switches the language.
  2. Enter the mobile number (e.g. 05XXXXXXXX) and the password, then sign in.
  3. The dashboard opens. The side menu has bookings, services, customers and the other sections your account's permissions allow; the Diet section shows only for diet companies.
تبقى مسجّلاًYou stay signed in
الجلسة محفوظة ومشفّرة لمستخدم Windows الحالي، فلا يُطلب الدخول عند كل تشغيل. كل مستخدم Windows على الجهاز له جلسته وإعداداته.The session is saved, encrypted for the current Windows user, so you are not asked to sign in at every start. Each Windows user on the PC has their own session and settings.

6عنوان الخادمServer address

يتصل البرنامج افتراضياً بالخادم https://api.dev.wrid.sa. لا تغيّره إلا بطلب من الدعم الفني. طريقتان للتغيير:

By default the app connects to https://api.dev.wrid.sa. Change it only when support asks you to. Two ways:

  • لهذا المستخدم: الإعدادات ← عنوان الخادم ← حفظ. يُسجَّل خروجك بعد التغيير.
  • لكل مستخدمي الجهاز: افتح المفكرة كمسؤول، وعدّل الملف C:\Program Files\Wrid MyReservation\appsettings.json. التحديثات اللاحقة تحافظ على هذا التعديل.
  • For this user: Settings → Server address → Save. You are signed out after the change.
  • For every user of the PC: open Notepad as administrator and edit C:\Program Files\Wrid MyReservation\appsettings.json. Later updates keep the edit.
{
  "ApiUrl": "https://api.dev.wrid.sa"
}
تنبيهCaution
الخادم api.dev.wrid.sa يعمل على قاعدة البيانات الحقيقية. كل حجز أو دفعة أو فاتورة تجريبية تُسجَّل فعلاً لدى الشركة. جرّب بحساب شركة تجريبية.api.dev.wrid.sa runs on the real database. Every test booking, payment or invoice is recorded for the company. Test with a test company account.

7التحديث والإزالةUpdate and remove

  • التحديث: شغّل ملف MSI للإصدار الأحدث بنفس الطريقة. يحلّ محل القديم مباشرة وتبقى الجلسة والإعدادات والطابعة وخيارات التثبيت كما هي. لا داعي لإزالة القديم أولاً. لا يمكن تثبيت إصدار أقدم فوق إصدار أحدث.
  • الإزالة: الإعدادات ← التطبيقات ← «Wrid وريد حجوزات» ← إلغاء التثبيت.
  • بيانات المستخدم (الجلسة، الإعدادات، الطابعة، السجلات) في %LOCALAPPDATA%\WridMyReservation، ولا تُحذف عند الإزالة. احذف المجلد يدوياً لإزالتها بالكامل.
  • Update: run the newer version's MSI the same way. It replaces the old one in place; the session, settings, printer and install options are kept. No need to uninstall first. An older version can't be installed over a newer one.
  • Remove: Settings → Apps → "Wrid وريد حجوزات" → Uninstall.
  • User data (session, settings, printer, logs) is in %LOCALAPPDATA%\WridMyReservation and is not deleted on uninstall. Delete that folder by hand to remove it completely.
